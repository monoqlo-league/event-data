# MONOQLO チーム戦ランキング データ

MONOQLO麻雀部 チーム戦(イベント戦)ランキングの集計元データを置くリポジトリ。
ランキングページはこのリポジトリのファイルを読み込んで、開くたびに集計する。

- ランキングページ: https://monoqlo-league.github.io/event-ranking/
- ページ本体は別リポジトリ(event-ranking)にあり、管理者だけが更新する。集計のルールは、そちらの README を参照。

## ファイル名のルール

1つの大会につき、次の3種類のCSVを置く。名前は **開始年4桁+開始月2桁+枝番2桁** で始める。
枝番は、同じ年月に大会が複数あるときの通し番号(ふつうは `01`)。

| ファイル名(2026年9月・枝番01の例) | 中身 | 作り方 |
|---|---|---|
| `20260901-master.csv` | 大会マスター(大会名、誰がどのチームか、リーグ構成) | 大会CSV作成ツール(event-create)で出力する |
| `20260901-schedule.csv` | 対局スケジュール(日程・卓組・席) | 対局スケジュール作成ツール(event-schedule)で出力する |
| `20260901-games1.csv` | 1次リーグの対局記録 | 雀魂の大会管理画面から「牌譜履歴」を書き出し、名前を変える |
| `20260901-games2.csv` | 2次リーグの対局記録 | 同上 |
| `20260901-games3.csv` | 3次リーグの対局記録 | 同上 |

- 対局記録はリーグごとに1ファイル。リーグが1つだけの大会でも、名前は `-games1.csv` にする。
- スケジュールは無くてもランキングは出る。ただし、リーグが終わったかどうかの判断と、対局前の卓組の表示ができなくなる(下の「スケジュールがない場合」)。
- 名前がルールと違うファイルは読み込まれない。
- 大会が2つ以上になると、ランキングページに大会を選ぶプルダウンが出る。最初に表示されるのは、名前の数字がいちばん大きい大会。

## 大会の進め方と更新手順

### 1. 大会の開始前

1. 大会CSV作成ツールで `…-master.csv` を作る。
2. 対局スケジュール作成ツールに `…-master.csv` を読み込ませ、`…-schedule.csv` を作る。2次以降のリーグの日程が決まっていなければ、「未定」にして作れる。
3. 2つのファイルをこのリポジトリに上げる(下の「ファイルの上げ方」)。

この時点で、ランキングページにはチームとメンバー、1次リーグのスケジュールが表示される。順位はまだ付かない。

### 2. 大会中

1. 雀魂の大会管理画面から「牌譜履歴」のCSVを書き出す。
2. ファイル名を、いま行っているリーグの名前に変える(1次リーグなら `…-games1.csv`)。
3. このリポジトリに上げる。同じ名前のファイルは上書きされる。

何度更新してもよい。その時点までの全対局が入ったCSVで上書きする。

### 3. リーグが終わったら

- そのリーグの対局記録の数が、スケジュールにあるそのリーグの対局の数に届くと、ランキングページは「終了」と判断する。
- 終了すると、上位チームが次のリーグに進み、次のリーグのスケジュールが表示される。
- **終わったリーグのファイルは、もう更新しない。** 次のリーグが始まってから前のリーグのファイルを上書きすると、次のリーグの対局が前のリーグに数えられてしまう。

### 日程が未定だったリーグの日程が決まったら

1. 対局スケジュール作成ツールに `…-master.csv` を読み込ませる。このリポジトリの `…-schedule.csv` が、続けて読み込まれる。
2. 未定のリーグのチェックを外し、対局数と開始日を入れて、出力する。ほかのリーグの組み合わせは変わらない。
3. 出力した `…-schedule.csv` を、このリポジトリに上げて置き換える。

日程や卓の名前を直すときも、同じ手順で読み込んで、直して、置き換える。

### 4. 次のリーグ

次のリーグの対局記録は、番号を1つ増やした名前で上げる(`…-games2.csv`)。

- 雀魂でリーグごとに別の大会を立てた場合: その大会の牌譜履歴を、そのまま上げる。
- 雀魂で1つの大会を続けて使う場合: 牌譜履歴には前のリーグの対局も入っている。そのまま上げてよい。前のリーグのファイルにある対局は、自動で除かれる。

## ファイルの上げ方

1. このリポジトリのページ上部にある **「Add file」→「Upload files」** を押す。
2. CSVを画面にドラッグ&ドロップする。同じ名前のファイルがあれば上書きされる。
3. 下の **「Commit changes」** を押す。
4. 5分ほど待ってから、ランキングのページを再読み込みする。

### 注意

- 反映には最長で5分ほどかかる。変わらないときは、強制再読み込み(Ctrl+F5。スマホなら一度タブを閉じて開き直す)を試す。
- 間違ったファイルを上げても、そのファイルを開いて「History」から前の版に戻せる。
- ファイルを消すと、その大会やリーグの表示が消える。過去の大会のファイルは消さない。

## 各ファイルの中身

文字コードは、どれも UTF-8(BOM付き)。Excelでそのまま開ける。

### 大会マスター(`-master.csv`)

1行が1人。

```
大会名,チーム名,プレイヤー名,プレイヤーID,役割,リーグ構成
第一回フォーサムリーグ,チームA,プレイヤー1,100000001,リーダー,予選:12/セミファイナル:8:50/ファイナル:4:50
第一回フォーサムリーグ,チームA,プレイヤー2,100000002,,予選:12/セミファイナル:8:50/ファイナル:4:50
```

| 列 | 中身 |
|---|---|
| 大会名 | ランキングページの見出しになる |
| チーム名 | 省略しない正式な名前を入れる。ランキングページにそのまま表示される |
| プレイヤー名 | 表示用。対局記録との照合には使わない |
| プレイヤーID | 雀魂のID(数字)。対局記録とは、このIDで照合する |
| 役割 | 各チームのリーダーの行に `リーダー` と入る。ほかは空欄 |
| リーグ構成 | 全行に同じ値。`リーグ名:チーム数:持ち越しの%` を「/」でつないだもの |

リーグ構成の例 `予選:12/セミファイナル:8:50/ファイナル:4:50` は、次の意味になる。

- 予選は12チーム。
- セミファイナルには上位8チームが進み、予選の合計PTの50%を持ち越す。
- ファイナルには上位4チームが進み、セミファイナルの合計PTの50%を持ち越す。

### 対局スケジュール(`-schedule.csv`)

1行が1チーム。

```
大会名,リーグ,チーム,対局数,開始日,開催曜日,1日の試合数,卓,第1戦,第2戦,…
第一回フォーサムリーグ,予選,ネコババしちゃったキジュトラ,24,2026-09-05,月水土,2,薔薇/金木犀/向日葵,2026-09-05(土) 向日葵 東,2026-09-05(土) 向日葵 南,…
第一回フォーサムリーグ,セミファイナル,予選1位,16,2026-10-03,月水土,2,薔薇/金木犀,2026-10-03(土) 金木犀 東,…
```

| 列 | 中身 |
|---|---|
| リーグ | 大会マスターのリーグ構成と同じ名前 |
| チーム | 1次リーグはチーム名。2次以降は「予選1位」のような順位の枠 |
| 対局数 | そのリーグで1チームが打つ数 |
| 開始日・開催曜日・1日の試合数 | 日程を決めたときの設定 |
| 卓 | そのリーグで使う卓の名前を「/」でつないだもの。ランキングページは、この順に卓を並べる |
| 第1戦、第2戦、… | 「日付(曜日) 卓の名前 席」。同じ回戦で同じ卓の4チームが対局する。抜け番は `2026-09-05(土) 抜け番` |

- **1次リーグの行のチーム名は、大会マスターのチーム名と同じにする。** 違っていると、スケジュールと対局記録を結び付けられない。チーム名を直すときは、両方のファイルを直す。
- 2次以降のリーグの枠(「予選1位」など)には、前のリーグが終わったあと、ランキングページが実際のチーム名を入れて表示する。
- 日程が未定のリーグは、行がない。そのリーグだけ、下の「スケジュールがない場合」と同じ扱いになる。
- 画面では、卓の名前のあとに「卓」を付けて表示する(「薔薇」→「薔薇卓」)。

### 対局記録(`-games1.csv` など)

雀魂の「牌譜履歴」のCSVそのまま。中身は書き換えない。1行が1局。

```
開始時間,終了時間,非表示状態,1位プレイヤー名,1位PT,1位最終点数,2位プレイヤー名,…,牌譜リンク,備考
```

- プレイヤー名は `[JP][100000001]プレイヤー1` の形。集計は、名前ではなく **プレイヤーID(数字)** で行う。途中で名前を変えた人も、同じ人として合算される。
- 「N位PT」は終了時の点棒(例: 34300)。「N位最終点数」がランキングで使うPT(例: 54.3)。
- 「非表示状態」が yes の対局は集計に含めない。
- 席(東南西北)の情報は入っていない。そのため、対局後のスケジュール表示には席を出さず、着順で並べる。

## スケジュールと対局記録が違うとき

ランキングページは、対局記録を優先する。

- 対局記録のある回戦は、組み合わせも日付も、対局記録のものを表示する。
- 対局記録を開始時刻の順に並べて回戦に分け、1番目の回戦をスケジュールの第1戦、2番目を第2戦…にあてる。

## スケジュールがない場合

`-schedule.csv` を置かない大会と、`-schedule.csv` に行がないリーグ(日程が未定のリーグ)は、次のようになる。

- スケジュールのタブには、終わった対局の結果だけが出る。
- リーグが終わったかどうかを判断できない。前のリーグが始まっていれば、その時点の上位チームを、次のリーグに進むチームとして仮に表示する。
- 見出しの「終了」「完了」の印は出ない。
